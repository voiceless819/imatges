# 🖼️ Imatges — Suite d'Eines d'Imatge

Una suite moderna, 100% privada, gratuïta i sense límits per al processament d'imatges directament des del navegador (sense pujar cap fitxer a servidors externs).

---

## 🚀 Eines Incloses

### 1. 💧 Marca d'Aigua en Lot (`marca-de-agua.html`)
- **Processament massiu per lots:** Afegeix la teva marca, copyright o logotip a múltiples imatges alhora.
- **Patró Mosaico (360°):** Protegeix tota la superfície de la imatge amb un patró repetitiu regulable en densitat i rotació.
- **Porta-retalls ràpid:** Enganxa imatges directament amb `Ctrl + V` (o `Cmd + V`).
- **Control total d'estil:** Fonts tipogràfiques, opacitat, color, mida i posició exacta.
- **Exportació avançada:** Còpia al porta-retalls amb 1 clic, descàrrega individual o paquet complet en `.ZIP` amb noms seqüencials.
- **Memòria persistent:** Desa automàticament la configuració i les imatges a `localStorage`.

### 2. 🪄 Quitar Fondo / Treure el Fons (`quitar-fondo.html`)
- **Alternativa completa a Remove.bg** (lliure, local i sense subscripcions).
- **Sense pèrdua de resolució:** Conserva el 100% de la mida i qualitat original de la imatge (fins i tot 4K o alta definició).
- **Motor d'Intel·ligència Artificial al navegador:** Executat mitjançant WebAssembly / WebGPU (BiRefNet / ISNet / RMBG-1.4).
- **Substitució de Fons (Edit Background):**
  - Fons Transparent (PNG clàssic per a disseny i botigues online).
  - Colors Sòlids amb paletes d'estudi predefinides i selector lliure de color.
  - Imatge de fons personalitzada o fons d'estudi integrats.
  - Efecte de desenfocament de fons regulable (**Bokeh estil retrat DSLR**).
- **Pinzell de Retoc Manual (Erase & Restore):**
  - Eina per **esborrar** residus del fons.
  - Eina per **restaurar** detalls fins (cabell, roba, accessoris).
  - Cursor interactiu amb diàmetre en temps real i mida de pinzell ajustable.
- **Comparativa interactiva Abans / Després (Split Slider)** per revisar el resultat amb precisió.
- **Exportació en PNG transparent, JPEG, WEBP i descàrrega en lot .ZIP**.

Punt d'accés central amb previsualitzacions interactives en viu de les dues eines, barra de navegació unificada i accés ràpid amb 1 clic.

## 🛠️ Com utilitzar-ho

1. **En local:** Simplement fes doble clic sobre `index.html` per obrir el Hub al teu navegador habitual (Chrome, Edge, Firefox, Safari).
2. **A GitHub Pages:**
   - Puja el projecte al teu repositori.
   - Ves a **Settings** -> **Pages** -> Selecciona la branca `main` / arrel `/` -> Clica **Save**.
   - El teu lloc web quedarà publicat i accessible arreu del món!

## 💡 Com canviar el nom del repositori a GitHub (si vols fer-ho)

Tal com has indicat que vols gestionar el canvi directament:
1. Entra al teu repositori a GitHub: [github.com/voiceless819/marca-d-aigua](https://github.com/voiceless819/marca-d-aigua)
2. Fes clic a la pestanya **Settings** (Configuració).
3. A la primera secció **Repository name**, canvia `marca-d-aigua` per `Imatges`.
4. Fes clic al botó **Rename**.
5. Fes commit i push dels nous fitxers preparats a aquest directori!
