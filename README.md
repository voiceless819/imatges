# Imatges

Hub de herramientas de imagen en el navegador:
- **Marca de Agua (`marca-de-agua.html`):** Añade marcas de agua en lote a tus imágenes.
- **Quitar Fondo (`quitar-fondo.html`):** Elimina el fondo de tus imágenes sin pérdida de calidad y permite cambiarlo por color, imagen o desenfoque.

Abre `index.html` para acceder al hub.
